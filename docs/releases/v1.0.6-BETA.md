AutoScene 1.0.6 Beta can start a project from YouTube and TikTok links instead of video files. Install the free Reel In plugin, paste your links, pick a quality, and each video joins your project and gets analysed as soon as it's downloaded.

## What's new

- **Projects from links.** Get **Reel In** under **Settings → Plugins → Browse**. **New project** then has **Add links…** next to Add folder and Add files: paste one YouTube or TikTok link or many, and create the project right away.
- **Pick the quality.** Best, 4K, 1440p, 1080p, 720p or 480p. Best takes the highest the video has.
- **Videos arrive one by one.** Each link downloads in Activity, and each video shows up in the project and is analysed as soon as it's done, so the first one is ready while the next is still coming. A card under the project's title shows how far it is.
- **Whole playlists.** A playlist or profile link brings up to 100 videos, numbered in their order.
- **Add more later.** A project's Overview and Episodes have **Add links…** too.
- **Safer database.** AutoScene now uses the latest SQLite, which fixes a security flaw.

## Before you install

- **Already installed?** The app updates itself (**Settings → Updates**). Your projects and models are kept.
- **Reel In needs this version.** AutoScene 1.0.5 and older can't install it.
- **Download only videos you have the right to use.** Videos that need you signed in (age-restricted, members only) and live streams can't be downloaded; each says why when it fails.
- **Not tried on a real Mac yet.** We tested on virtual Macs, so speed, heat and some features may differ on yours. Linux hasn't run on a real desktop either, so please tell us what you see.
- **Not signed by a publisher yet,** so the first start needs your OK. On Windows, choose **More info → Run anyway**. On macOS, drag AutoScene to Applications and open it, then choose **Open Anyway** in **System Settings → Privacy & Security** and confirm. With Smart App Control on, Windows 11 offers no such choice and blocks the installer. If macOS later refuses a part of the app, the fix is in the full list at the very end.

## Check your download

Each file comes with a signed record (a build attestation) of the workflow
of [tcmmi/AutoScene](https://github.com/tcmmi/AutoScene) that built it, and
the tag and commit it was built from. To check one, use the
[GitHub CLI](https://cli.github.com), signed in with any GitHub account:

```bash
gh attestation verify AutoScene_1.0.6-BETA_x64-setup.exe -R tcmmi/AutoScene
```

To insist on this tag and the release workflow, add
`--source-ref refs/tags/v1.0.6-BETA --signer-workflow tcmmi/AutoScene/.github/workflows/release.yml`.

Or compare SHA-256 hashes: put `SHA256SUMS` next to your downloads and run
`sha256sum --check --ignore-missing SHA256SUMS` (Linux) or
`shasum -a 256 --check --ignore-missing SHA256SUMS` (macOS). In PowerShell
on Windows, this prints `True` for an intact download:

```powershell
(Get-FileHash .\AutoScene_1.0.6-BETA_x64-setup.exe).Hash -eq (-split (Select-String -Path SHA256SUMS -Pattern x64-setup.exe -SimpleMatch).Line)[0]
```

## Everything in this release

### Links instead of files

- **Reel In.** A free plugin from the AutoScene catalog (**Settings → Plugins → Browse**), by tcmmi. It downloads with yt-dlp and joins picture and sound with AutoScene's own FFmpeg, without re-encoding. Its first run downloads what it needs, about 50 MB.
- **Add links….** With a plugin that takes links, **New project** has **Add links…**. Paste links, one per line: each shows whether a plugin takes it. The quality choice sits right there. You can mix links with files, or create a project from links alone.
- **Where videos go.** Into the **Downloads** folder of your AutoScene library, in a folder named after the project. Removing the project leaves them there.
- **Downloads in the background.** Downloads run one after another in Activity, apart from analysis and exports, and you can stop any of them. A download that fails says why. Links still waiting when you quit AutoScene are picked up again at the next start.
- **In a project.** **Add links…** is in the Overview (the ⋯ menu and right-click) and in Episodes (the button at the top and right-click). A card under the title shows the running download and how many wait, and an empty project says its videos are on their way.
- **Limits.** YouTube and TikTok only. No live streams, and no videos that need you signed in. YouTube changes often: when downloads break, a new Reel In version fixes them, and it updates from the plugin list. On Windows on ARM, YouTube works only partly.

### For plugin authors

- **Sources.** A plugin can now take links: it names the sites it handles, AutoScene runs it once per link with a folder to download into, and it hands back each finished video. The plugin guide has a new Sources section, and the install and update reviews say when a plugin adds one.

### Safety

- **SQLite 3.54.1.** The database engine inside AutoScene is updated past a flaw that could show stale memory when opening a crafted database file (CVE-2026-119375).

### Installing and updating

- **Not tried on a real Mac yet.** This version was built and tested on GitHub's virtual Macs, which have no Neural Engine or GPU, so a real Mac may behave differently. Linux has run in CI and WSL only, not on a real desktop. If you try either, please tell us what you see.
- **First start on macOS, step by step.** Drag AutoScene to Applications, open it and close the message that macOS can't verify it. Then open **System Settings → Privacy & Security**, scroll down to the note about AutoScene, choose **Open Anyway** and confirm. (Since macOS 15, right-click → Open no longer does this.) If macOS later refuses a part of the app, such as `libonnxruntime.dylib`, run `xattr -dr com.apple.quarantine /Applications/AutoScene.app` once.
